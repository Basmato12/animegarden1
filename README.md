## 🌐 How to Host

### Option 1: Free Hosting (Netlify, Vercel, GitHub Pages)
1. Create a GitHub repository
2. Upload all 5 HTML files
3. Deploy using Netlify, Vercel, or GitHub Pages
4. Your site will have a free URL like: `your-site.netlify.app`

### Option 2: Paid Hosting (Bluehost, GoDaddy, SiteGround)
1. Upload all 5 HTML files via FTP
2. Point your domain to the hosting
3. Website will be live at your custom domain

### Option 3: Local Server (for testing)
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js
npx http-server
```
Then visit: `http://localhost:8000`
